Context Protection

Hierarchical Subagent Swarms

Large multi-turn tasks rapidly deplete LLM context windows. Nolthira spawns child subagents with strictly scoped tools and sandboxes, returning only the synthesized conclusion to the parent.

delegate_task(role="sec_auditor", goal="Audit pyproject.toml against known CVEs") ✔ Worker [auditor-1]: Scoped context (32k) · 0 vulnerabilities detected
Persistent Retention

SQLite FTS5 Long-Term Memory

Never re-explain your database schema or coding style. Facts, architectural decisions, and credentials survive reboots in ~/.nolthira/nolthira_memory.db with BM25 full-text indexing.
