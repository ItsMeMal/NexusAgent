The Terminal Orchestrator
for Autonomous Multi-Agents.

A persistent, sandboxed CLI runtime featuring hierarchical subagents, local multimodal vision, Model Context Protocol (MCP), and SQLite FTS5 memory — running entirely in your local terminal.

Built for Production Autonomy

Engineered around isolated subagent contexts, persistent full-text retrieval, and strict defensive security.

Multi-Agent Engine
Hierarchical Subagent Delegation
The primary orchestrator breaks large multi-stage objectives into scoped leaf subagents via delegate_task. Subagents execute in parallel with isolated context windows, preventing prompt saturation.
delegate_task(role='researcher', task='Analyze OWASP CVEs in requirements.txt')
✔ subagent: Spawned subagent [worker-4a] · Executed in isolated 32k context · Returned synthesis
Multimodal Vision
Local Image & Diagram Inspection
Direct vision tool view_image to analyze local UI mockups, architecture diagrams, and error screenshots without external uploading.
view_image('./mockup.png')
✔ Extracted 4 UI layout inconsistencies
Full-Text Memory
SQLite + FTS5 Retrieval
Automatic long-term persistent fact retention across all terminal sessions. Keyword and semantic full-text indexing in ~/.nexus/nexus_memory.db.
recall_memory('active deployment targets')
✔ Recalled staging & prod infra specs
Extensibility
MCP Protocol & Python Plugins
Connect external tools via standard .mcp.json (stdio & SSE), or drop dynamic modular Python tools into plugins/.
/mcp ➔ 3 servers connected (Postgres, GitHub, FS)
/plugins ➔ Loaded custom workflow modules
Security Shield

Terminal Slash Commands

Type / in the prompt to access the full interactive command palette.

Command Category Action
/provider Inference Routing Interactive menu to switch routers (OpenRouter, DeepSeek, Groq, Ollama, Custom URL).
/models Model Selection Live model catalog filter for the connected provider with arrow-key navigation.
/resume Session Management Browse past conversations stored in SQLite and resume context instantly.
/tools Runtime Telemetry Inspect all 19 online autonomous tools and their parameter schemas.
/mcp Extensibility Inspect connected Model Context Protocol (MCP) server endpoints.
/plugins Extensions View loaded modular Python extensions from plugins/.
/security Guardrails View active security policies, command sandbox status, and auto-approve settings.
/cron Automation View scheduled background jobs and automated recurring workflows.
/memory Persistent Storage Inspect persistent facts and architecture decisions stored in SQLite FTS5.

Home Directory Layout

Nexus installs globally into your standard operating system user profile.

Windows C:\Users\<username>\.nexus\
Linux /home/<username>/.nexus/ (or /root/.nexus/)
macOS /Users/<username>/.nexus/
Global Config ~/.nexus/.env (persistent across all directories)
Memory DB ~/.nexus/nexus_memory.db (SQLite FTS5 full-text index)
