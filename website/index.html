Home Directory Layout

Windows C:\Users\<username>\.nexus\
Linux /home/<username>/.nexus/ (or /root/.nexus/)
macOS /Users/<username>/.nexus/
Global Config ~/.nexus/.env (persistent API keys and active router)
Memory DB ~/.nexus/nexus_memory.db (SQLite + FTS5 full-text search)

Active Built-in Toolset (19 Tools)

Subsystem Tool Identifier Description
Filesystem & Code read_file, write_file, patch_file, list_dir, search_files Sandboxed file I/O and fast regex grep search.
Terminal Execution run_command Guarded asynchronous shell execution with destructive pattern interception.
Multimodal Vision view_image Direct visual inspection of local images, diagrams, mockups, and screenshots.
Web Intelligence web_search, web_extract Live search engine queries and clean readable article text extraction.
Persistent Memory store_memory, recall_memory, list_all_memories Full-text search indexed key-value memory engine across sessions.
Dynamic Skills list_skills, read_skill, create_skill Self-learning procedural workflows stored in .skills/*.md.
Background Tasks schedule_task, list_scheduled_tasks, cancel_scheduled_task Background cron scheduler for deferred or recurring jobs.
Multi-Agent Orchestration delegate_task Hierarchical subagent dispatching with scoped tools and isolated context.

Interactive Slash Commands

Command Function
/provider Select or connect an inference router (OpenRouter, DeepSeek, Groq, Ollama, Custom URL).
/models Browse and filter models for the connected provider with arrow-key navigation.
/resume Browse and restore previous chat sessions from SQLite database.
/tools List all active tools and inspect parameter schemas.
/mcp Inspect connected Model Context Protocol (MCP) server endpoints.
/plugins Inspect loaded modular extensions from plugins/.
/security View security policies, command sandbox status, and guardrails.
/memory Inspect long-term memory entries stored in SQLite FTS5.
/cron View active background tasks and scheduled automations.
/clear Clear terminal viewport and re-render header banner.

Security & Sandboxing

Command Guard Blocks rm -rf /, disk formatting, fork bombs, and raw device writes.
Secret Protection Blocks reading or modifying .env, SSH keys, private certificates, and credentials.
Path Isolation Prevents path traversal into system folders (C:\Windows, /etc, /bin).
Injection Shield Treats external web and document text as untrusted passive data.
