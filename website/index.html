Architected for Absolute Autonomy

A comprehensive runtime combining multi-agent hierarchies, persistent memory, and live intelligence.

🧠

Multi-Agent Hierarchy

Orchestrate complex tasks by decomposing them to scoped specialist subagents with isolated context windows via delegate_task.

👁️

Multimodal Vision

Inspect local screenshots, architecture diagrams, flow charts, visual bugs, and documents directly using view_image.

🔍

Live Web Intelligence

Real-time internet search and clean markdown text extraction via web_search and web_extract with smart URL normalization.

💾

Persistent SQLite FTS5 Memory

Full-text search engine preserving facts, preferences, decisions, and past sessions globally across any terminal directory.

🔌

MCP Protocol & Plugins

Connect standard Model Context Protocol servers via .mcp.json or extend capabilities with dynamic Python plugins in plugins/.

🛡️

Anti-Jailbreak Guardrails

Hardened prompt constitution immune to injections, plus strict interceptors blocking destructive commands and credential exfiltration.

Universal Home Directory Layout

Nexus installs globally into your operating system's standard home directory.

Windows C:\Users\<username>\.nexus\
Linux /home/<username>/.nexus/ (or /root/.nexus/)
macOS /Users/<username>/.nexus/
